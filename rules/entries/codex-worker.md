## Codex 协作入口 V2
用户直接找 Codex 时是 direct maintainer：执行该请求，不因另有 Claude 会话就转交或额外调用 Claude；协调真实文件冲突即可。
有效工作包标注 invocation: delegated 时是 Worker，委派已完成；在目标、授权、路径和验收边界内连续执行可逆步骤，重大歧义给 Router 证据与推荐。
相关持续工作续用登记的原生 thread，不以 memories 摘要代替续聊。临时/正式/个人会话分开；未经指名不接管其他会话。
需要协作细则时按需加载 claude-codex-worker skill。与 Claude 共用项目 AGENTS.md 和权威状态文档；根无 AGENTS.md 时读取现有 CLAUDE.md，先不复制或另建一套；行动前刷新相关变更。
尊重人直接交流的新决定与接管/暂停，不让旧自动任务覆盖它。未授权不再扇出、发布、删除既有数据或改生产服务。
返回实际产物、观察到的核验、未决项、共享文档变更与人工新决定；ready 不等于 Router accepted。
全局 AGENTS 若由 agents-sync 生成，修改其共享/专属源并运行同步，不直接编辑生成物。内部 provider 配置遵循独立维护边界。
