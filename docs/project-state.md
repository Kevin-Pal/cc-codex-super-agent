# Shared project state

The current public source snapshot is CC–Codex Super Agent 0.3.0, MIT licensed. Runtime, role skills and synthetic tests are included. The owner handles GitHub visibility; there is no package/tag/release publication automation.

The project combines the Claude Code Router and native Codex Worker harnesses, inspired by selected DeepSeek Super-agent ideas without a DSH runtime dependency or affiliation. The accountable Router, human intervention and a single logical project authority remain design goals.

Source installation targets Python 3.11+ and POSIX macOS/Linux. Native backend/control-endpoint availability is an explicit prerequisite; tested versions and unknown GUI builds are listed in harness-compatibility.md. Existing live-trial evidence and this snapshot's synthetic checks are distinguished in runtime-validation.md.

Automatic integration, shared external-resource coordination, interactive question/approval forwarding, long-duration wakeup improvements and automated schema/version inventory remain future work. Private operator deployment files, internal provider management and raw conversation logs remain out of scope.

Maintenance authority: AGENTS.md, README.md, SETUP.md and the task-relevant canonical guides. Public changes are reviewed snapshots or generic fixes, never automatic private-branch merges.

This documentation-review branch consolidates acceptance/lifecycle guidance without exporting the private 0.4.0 runtime. Filename-level same-tree leases are not planned; source installation on this branch is not evidence that the new policies were trialled in a live Router.
