# Publication boundary

This source snapshot is MIT licensed. The owner performs repository visibility changes. GitHub visibility is external state; a file in this repository does not change it. No package uploader, automatic mirror or release-tag workflow is enabled.

Before publishing or pushing a snapshot, review tracked files, the complete outgoing history, author identities, symlinks/references and source archives. Run the synthetic checks and the publication checker, then inspect findings manually. A scanner cannot guarantee absence of every secret or private fact.

Keep credentials, actual provider settings, real project memories/tasks, raw logs and private source mappings outside this repository. Never copy the private source repository's .git directory or merge its branches as an export mechanism. Preserve model/account/provider ownership boundaries and represent only observed platform/version evidence.

Source publication does not authorize installing into another user's environment or publishing packages/tags/releases. Future distribution automation and platform expansion need separate review.
