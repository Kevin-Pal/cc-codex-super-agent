# Security and privacy during preparation

Do not put tokens, authentication files, private keys, account identifiers, raw conversations, machine fingerprints or real task datasets into this repository or issue text. Use a minimal synthetic reproduction and sanitized metadata.

Role rules and Router guards guide authorized collaboration. They are not an OS isolation boundary; a trusted Worker may have broad tool capability, which does not widen the task's authorization. Keep private context out of work packages and results unless needed and authorized.

The preparation checker catches a limited set of file names, paths and secret-like strings. It does not establish that a snapshot or history is safe to publish. Human source/privacy review remains required.

Public vulnerability reporting channels and a supported-version policy will be defined before any public release.
